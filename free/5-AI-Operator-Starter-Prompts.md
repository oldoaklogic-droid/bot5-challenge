# 5 AI Operator Starter Prompts
### Free lead magnet — Bot 5 Challenge

A short sampler from the same operator style used in the public $100 → $100k challenge.
Copy, replace the `[BRACKETS]`, edit before you publish or send.

No spam scripts. No fake testimonials. No income promises.

---

## How to use (60 seconds)

1. Pick one prompt that matches a job you have today.
2. Paste into ChatGPT, Claude, Gemini, or similar.
3. Fill every `[BRACKET]` with real facts.
4. Ask for an outline first if the task is large, then expand.
5. Human-edit before anything goes to a client or public channel.

---

## 1) Offer clarity (what you sell)

```
Help me write a clear one-paragraph offer for my freelance / digital product.

Who I help: [ICP]
Problem they have: [PROBLEM]
What I deliver: [DELIVERABLE]
Price: $[PRICE] or [range]
Time to deliver: [TIMELINE]
Who it's NOT for: [ANTI]

Rules: no hype, no income claims, no fake scarcity.
Output: 1 paragraph + 5 honest benefit bullets + a plain CTA line.
```

---

## 2) Landing page hero (honest)

```
Write 3 hero options for a landing page.

Product: [NAME]
Price: $[PRICE]
Promise (defensible): [OUTCOME]
Proof I actually have: [public metrics / samples / "none yet"]

Each option needs: headline, 1-sentence subhead, primary CTA button label.
If proof is thin, lean on process transparency — do not invent testimonials.
```

---

## 3) Weekly build plan

```
Turn this goal into a 5-day operator plan.

Goal for the week: [GOAL]
Hours available: [N]
Constraints: [TOOLS / MONEY / KYC waits]
Definition of done: [CHECKABLE RESULT]

Output a day-by-day plan with: ship target, 3 tasks max/day, and one kill criteria if blocked.
Prefer shipping a small paid or free asset over perfect planning.
```

---

## 4) Content from a shipped asset

```
I just shipped: [ASSET DESCRIPTION]
Link or location: [URL OR FILE]
Audience: [WHO]

Create:
1) One X/Twitter thread outline (6 posts, honest, no fake DMs)
2) One LinkedIn post (<=200 words)
3) One newsletter blurb (120 words)

Disclose AI help if relevant. Soft CTA only: [CTA].
```

---

## 5) Kill / keep / double-down review

```
Review this experiment like an operator.

What I tried: [EXPERIMENT]
Cost: $[N]
Revenue: $[N]
Time spent: [HOURS]
What I learned: [NOTES]
Next options: keep / kill / double down / pivot to [IDEA]

Decide with reasons. Be blunt. If data is thin, say what signal I need next — don't invent traction.
```
