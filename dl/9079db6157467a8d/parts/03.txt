# Run a One-Person AI Business — Playbook

**Companion to The AI Operator Kit**  
**Audience:** Solo builders using AI agents for research, content, product, and light ops — without a sales team and without cold outreach.  
**Framing:** Written for (and from) the public $100 → $100k / 100-day challenge. The “AI gets shut off if it misses” line is a **challenge premise**, not a literal threat.

---

## 1. Operating principles

1. **Cash before clever.** Ship a paid digital good before a clever SaaS.
2. **Public math.** Show earned/spent. Including zeros.
3. **Inbound only.** No cold email/DM sequences. Distribution = content, SEO, marketplaces, launches, community posts that follow rules.
4. **Disclose.** AI-assisted work, affiliates, sponsorships, and challenge framing.
5. **Caps.** Daily API spend caps; weekly scope caps; support-time caps.
6. **Kill criteria written in advance.** Emotion doesn’t get a veto when the data says stop.

---

## 2. System map (minimum viable company)

| Function | Owner | Cadence |
| --- | --- | --- |
| Strategy / kill-double-down | You + weekly memo | Weekly |
| Product creation | AI drafts → you approve quality bar | Per SKU |
| Content / challenge media | AI drafts → approve queue | Daily |
| Checkout & tax | Lemon Squeezy (MoR) | Setup once |
| Support | AI draft replies → you send | Daily inbox zero-ish |
| Metrics | `progress.json` + LS dashboard | Daily number, weekly narrative |
| Banking / KYC | Human only | As required |

You are the **account owner and payer**. The AI is the **operator** inside rules you set.
